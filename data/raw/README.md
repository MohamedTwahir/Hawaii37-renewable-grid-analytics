## Project Title
Machine Learning Based Prediction of Voltage and Trnsmission Congestion Risks When Increasing Renewable Energy Penetration: A study of the Synthetic Hawaii 37-Bus Power System.
## Dataset Attribution

This project uses the Hawaii 37-Bus Synthetic Power System developed and made publicly available by researchers at Texas A&M University through the Electric Grid Test Case Repository.

The dataset is a synthetic representation of the geographic footprint of Oahu, Hawaii, and does not represent the actual Hawaiian electricity grid.

Original dataset: https://electricgrids.engr.tamu.edu/hawaii40/

The original dataset is provided by Texas A&M University researchers for free commercial and non-commercial use. Users are encouraged to complete the dataset usage form and cite the associated research publications.

All additional simulation scenarios, data processing, machine learning models, visualizations, and analyses in this repository were developed as part of this independent research project.
